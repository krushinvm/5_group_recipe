# Сервис подбора рецептов

Прототип RESTful-сервера на Python (FastAPI) для добавления рецептов и подбора блюд по имеющимся продуктам.

## Описание эндпоинтов

| Название действия | Локейшн (URL) | Тип запроса | Описание запроса и ответа |
| :--- | :--- | :--- | :--- |
| Проверка статуса | `/` | GET | Возвращает `{"status": "ok", "message": "Recipe Finder API is running"}`, если сервер работает. |
| Добавить рецепт | `/recipes` | POST | Принимает JSON: `name` (название), `rating` (рейтинг 0-5), `ingredients` (список продуктов и их количество). Возвращает созданный рецепт с присвоенным `id`. |
| Подобрать рецепты | `/recipes/search` | POST | Принимает JSON-массив продуктов пользователя. Возвращает список подходящих рецептов (с учетом количества ингредиентов), отсортированных по убыванию рейтинга. |
