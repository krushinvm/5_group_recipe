# Сервис подбора рецептов (Recipe Finder API)

RESTful-сервер на Python (FastAPI + MongoDB) с веб-интерфейсом для добавления рецептов с пошаговыми инструкциями и подбора блюд по названию или имеющимся продуктам.

## Описание эндпоинтов

| Название действия | Локейшн (URL) | Тип запроса | Описание запроса и ответа |
| :--- | :--- | :--- | :--- |
| Проверка статуса | `/` | `GET` | Проверяет работу сервера и подключение к MongoDB. Возвращает `{"status": "ok", "db": "connected"}` (или `503`, если БД недоступна). |
| Добавить рецепт | `/recipes` | `POST` | Принимает JSON: `name` (название), `rating` (от 0 до 5), `ingredients` (массив с `name`, `quantity`, `unit`) и `instructions` (пошаговый способ приготовления). Возвращает созданный рецепт с `id` (HTTP `201`). |
| Поиск по названию | `/recipes?name=...` | `GET` | Ищет рецепты по частичному совпадению названия без учёта регистра. Если `name` не передан, возвращает все рецепты. Сортировка по убыванию рейтинга. |
| Подобрать рецепты | `/recipes/search` | `POST` | Принимает JSON-массив продуктов пользователя (`name`, `quantity`, `unit`). Возвращает рецепты, в которых совпал хотя бы один ингредиент, отсортированные по убыванию рейтинга. |

## Стек технологий
- **Backend:** Python 3.11+, FastAPI, Pydantic, Motor (MongoDB)
- **Frontend:** HTML, CSS, JavaScript (`index.html`)
- **Тесты и CI:** Pytest, pytest-asyncio, mongomock-motor, Flake8, GitHub Actions

## Запуск проекта

1. Склонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   git clone https://github.com/krushinvm/5_group_recipe
   cd 5_group_recipe
   python -m venv .venv
   ```
2. Активируйте окружение и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Убедитесь, что локально запущена **MongoDB** (`mongodb://localhost:27017`).
4. Заполните базу стартовым набором из 22 рецептов с инструкциями:
   ```bash
   python seed.py
   ```
5. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```
6. Откройте:
   - **Swagger UI:** `http://127.0.0.1:8000/docs`
   - **Веб-интерфейс:** откройте `index.html` в браузере.

## Запуск тестов и проверка покрытия

pytest --cov=main --cov-fail-under=80 -v
